# Supermarket Sales Analysis Dashboard | Tableau

## Project Overview

This project presents an interactive Supermarket Sales Dashboard developed using Tableau. It analyzes supermarket sales transactions to understand revenue performance, product demand, customer purchasing behavior, payment preferences, and sales patterns across different branches and cities.

The dashboard helps explore key business metrics and customer insights through interactive filters and visualizations.

## Key Analysis & Visualizations

The dashboard covers the following business areas:

1. **Product Category Analysis:** Analyzes product counts across different supermarket categories.
2. **Gender-wise Customer Analysis:** Compares customer distribution by gender.
3. **Customer Type Analysis:** Examines Member and Normal customer purchasing patterns.
4. **Sales by Hour:** Analyzes average sales quantity across different hours of the day.
5. **Branch-wise Customer Analysis:** Compares customer types across supermarket branches.
6. **City-wise Payment Analysis:** Visualizes payment method distribution across cities.
7. **Payment Method Analysis:** Provides an overview of customer payment preferences.

## Dashboard Filters

The dashboard includes interactive filters for:

- Payment Method
- Customer Type
- Gender

These filters allow users to explore different customer segments and payment patterns.
